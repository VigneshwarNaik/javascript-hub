# JavaScript Hub 🚀

A structured repository for learning **JavaScript from basics to advanced** with clean examples, organized folders, and beginner-friendly notes.

## 📂 Repository Structure

* `variables/` – `var`, `let`, `const`
* `datatypes/` – primitive & non-primitive types
* `type-conversion/` – string, number, boolean conversion
* `operators/` – arithmetic, comparison, logical, ternary
* `prompt/` – input examples using prompt
* `loops/` – for, while, do...while
* `scopes/` – global, function, block scope
* `chain/` – scope chain examples
* `objects/` – object creation, functions as objects
* `strings/` – important string methods
* `dom/` – DOM manipulation examples
* `asynchronous/` – callbacks, timers, async concepts
* `promise/` – promises, async/await, execution order
* `basics/` – foundational JavaScript examples

## 🎯 What You’ll Learn

✅ Core JavaScript fundamentals
✅ Problem-solving concepts
✅ DOM and browser scripting
✅ Asynchronous JavaScript
✅ Modern ES6+ concepts
✅ Interview preparation topics

## 🛠 How to Run Code

1. Install **Node.js**
2. Open terminal in project folder
3. Run files:

```bash
node filename.js
```

Example:

```bash
node strings/index.js
```
